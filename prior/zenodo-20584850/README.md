# Earlier work: the June 2026 Zenodo package

These files come from the Zenodo record **al-Battani: Opus Astronomicum / Kitab al-Zij, Text Working Edition and Audited Table Data**:
- concept DOI [10.5281/zenodo.20539593](https://doi.org/10.5281/zenodo.20539593)
- latest version [10.5281/zenodo.20584850](https://doi.org/10.5281/zenodo.20584850) (version label "2026-07-02 work-level status wording refresh")
- licensed CC0 1.0

The files marked "here" are byte-identical to Zenodo (MD5 checked). The large packages stay on Zenodo only.

## What it contains

- A **251-page text working edition**: 100 body-text segments as Arabic source with English and Chinese translations.
- A **fixed-star catalogue**: 485 numbered star rows across 47 Ptolemaic figures, as data plus a PDF.
- A **geographical gazetteer** of 269 localities, as data plus a PDF.
- A **partial chronology / Canon of Kings**, as data plus a PDF.
- The **v083 canonical reference**: TeX, data and reports.
- A **table reference supplement** and the **lessons learned** from the table reconstruction.

## Status

This is earlier work, made before the source-gated S01–S16 workflow used in the rest of this repository. Under that workflow it is continuity material: useful and checkable, but to be replayed against the Nallino scans before reuse.
- The reader interleaves Arabic, English and Chinese. That predates the current rule of one separate edition per language.
- Words like "Complete Critical Edition" in file names are inherited labels, not certified claims.
