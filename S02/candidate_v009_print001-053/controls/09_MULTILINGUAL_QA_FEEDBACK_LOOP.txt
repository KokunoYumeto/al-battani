Operational interpretation
--------------------------
1. The corpus boundary is the full reasonably discoverable author corpus, with exact inaccessible/lost/unverified gaps; it is not the current local packet, a single work, or the currently translated subset.
2. The canonical source-language edition remains the shared correction target and must stay traceable to source pixels.

4. A translation never silently patches the canon. It returns evidence-backed proposed corrections with source coordinates, affected canonical anchors, reasoning, confidence, and propagation impact.
5. Accepted canonical corrections create a new canonical checkpoint/version. Every language edition records which canonical checkpoint it tracks, periodically checks for later canonical changes, and integrates applicable corrections without erasing its earlier release history.
6. A later language translation is another independent semantic/source reading and may discover errors missed by earlier passes. Its findings route back to the same canon and then outward to every affected language.
7. Multilingual feedback is additive QA, not a substitute for initial source replay, formula/diagram inspection, deterministic build/render validation, unresolved-reading disclosure, or independent audit.
8. Packet prompts and return protocols must expose this loop explicitly through a canonical-version field, source-check findings ledger, correction-routing ledger, and translation synchronization receipt.
